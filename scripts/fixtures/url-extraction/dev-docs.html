API Cache

createCache

Creates a cache instance. The returned object owns its own entry map, so two instances never share state. Call createCache once per application and pass the result down through context.

Signature

export function createCache(options: CacheOptions): Cache {
	const entries = new Map<string, Entry>();

	return {
		get(key) {
			return entries.get(key)?.value;
		},
		set(key, value) {
			entries.set(key, { value, storedAt: Date.now() });
		},
	};
}

Options

Every option is optional. The defaults are tuned for a single page application that navigates frequently between a small number of routes.

Option Type Default Description
maxEntries number 500 Entries kept before the least recently used one is dropped.
staleTime number 0 Milliseconds an entry is served without a background refetch.
onEvict function undefined Called with the key and value whenever an entry is removed.

Usage

Wire the instance into the provider at the root of the tree. The staleTime value below keeps results warm for a minute. 

const cache = createCache({
	maxEntries: 1000,
	staleTime: 60_000,
});

export function App() {
	return (
		<CacheProvider value={cache}>
			<Routes />
		</CacheProvider>
	);
}
